# 3D Chess Game — OpenGL Rendering Engine
---
## Project Overview

This application is a 3D reinterpretation of chess, designed to explore computer graphics, mathematical modeling, and interactive rendering techniques.

The goal was to build a modular OpenGL-based rendering engine capable of supporting interactive gameplay visualization.

Since the theme was free, we chose awards to replace the traditionnal chess pieces.

---

## Core Features

- Real-time **3D rendering using OpenGL**
- Fully modeled **3D chessboard with volumetric tiles**
- Custom **3D chess pieces**
- Interactive **piece selection system**
- Ray-casting-based **mouse picking for scene interaction**
- Trackball **camera system**:
- Skybox-based **3D environment rendering**

---

## Technologies

- C++
- OpenGL
- GLSL (shaders)
- Dear ImGui (UI integration)
- Linear algebra (geometry, projections, intersections)
